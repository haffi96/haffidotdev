A dashboard for monitoring LiveKit rooms: list active rooms, join one, and watch every camera feed in a video grid.

It needs no server configuration: you enter LiveKit credentials in the UI. Each video track can expand to show detailed WebRTC stats, and a telemetry panel visualises data-channel messages in real time, with message rate, size statistics and a rolling message stream. I built it for debugging low-latency video pipelines.
